# Heroicons

These SVG files are unmodified Heroicons 24px outline assets, version 2.2.0.
Source: https://github.com/tailwindlabs/heroicons/tree/v2.2.0/optimized/24/outline
Copyright Tailwind Labs, Inc. The adjacent LICENSE is the upstream MIT license.
These local files require no icon service, font download or runtime dependency.

Evidence uses exclamation-circle for the referenced failed finding and
information-circle for neutral related context. Icons float beside actual tokens;
they never replace or insert captured characters.
