## 保留的明确边界

- A：开发 harness、容器、首个固定协议包、4 个可执行基础 API case 与离线检测器验收；默认 basic 仅 3 请求。
- B：真实流式工具、多轮闭环和有限版本矩阵；C：固定 CLI 的真实任务与锁定建议；D：重复/重试、比较、重评分、脱敏导出和周期更新流程。
- API 日期、beta、规则快照、检测器实现及客户端/服务交付分别记录；发送头不等于服务遵循该版本。
- 容器 Linux CLI 与宿主原生 CLI 分别验收；纯离线质量门禁不访问真实目标。
- 后续实施阶段确定精确依赖版本、基础镜像摘要、可用 Claude CLI 发行渠道与 CI 平台；不得把未获取的摘要或未运行的架构写成已验证。
