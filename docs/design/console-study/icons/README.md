# Heroicons used by the interaction study

These SVGs are unmodified Heroicons 24px outline assets, version 2.2.0.
Source: https://github.com/tailwindlabs/heroicons/tree/v2.2.0/optimized/24/outline
The adjacent LICENSE is the upstream MIT license, copyright Tailwind Labs, Inc.

The sample displays them at 14px in neutral tones with visible or accessible labels.
Chevron-right is rotated for back navigation. CSS masks use the local files;
there is no icon service, font download or JavaScript dependency.

The evidence annotation study also uses exclamation-circle for a sample fault
and information-circle for neutral related context. Both are displayed at 15px
inside a keyboard-accessible gutter button, without changing JSON indentation.
